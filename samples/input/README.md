# Input samples (local only)

Place **your own** test media here. File blobs are gitignored — do not commit biometric imagery.

Suggested filenames:

| File | Purpose |
|------|---------|
| `clip.mp4` | Short clip with a visible face (used for video pipeline) |
| `avatar.jpeg` | Avatar or face reference for Phase 1 single-frame tests |

Until `assets/avatars/*.png` exist, `avatar.jpeg` stands in for the gallery avatar in `plan.md` Phase 1.

Consent and usage should be documented in the project report / `ETHICS.md`.
